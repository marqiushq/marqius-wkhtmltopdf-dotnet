# The languages picture on the package's page

This folder makes the page of eight languages shown on [Marqius.DinkToPdf](https://www.nuget.org/packages/Marqius.DinkToPdf)'s page.

```bash
dotnet run
```

Then open `languages.pdf`. Letters are drawn with the fonts installed on the computer: on a Linux server, install them first, as [the manual](https://github.com/marqiushq/marqius-wkhtmltopdf-dotnet/blob/main/docs/manual.md#8-other-languages-and-fonts) shows.
